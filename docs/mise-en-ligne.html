Mettre en ligne la synchro de groupe

Quatre étapes, une dizaine de minutes. Seules les deux premières demandent ton compte Cloudflare ; Claude peut faire les deux suivantes à ta place.

Le relais est une petite boîte aux lettres sur Internet. Chaque appareil y dépose et y reprend les chansons du groupe, chiffrées : le relais ne peut pas les lire. Il sert à trois choses : la synchro par code de groupe, l'envoi des partitions PDF, et la session live.

Ton worker Cloudflare existe déjà (il sert à la recherche d'accords). Il faut lui envoyer la nouvelle version, puis dire à l'application où il se trouve.

1

Se connecter à Cloudflare

toi · 2 min

Ouvre un terminal et va dans le dossier du worker, avec le code à jour :

cd ~/Projects/open-setlist
git switch main
git pull
cd worker

Puis lance la connexion :

npx wrangler login

Une page Cloudflare s'ouvre dans le navigateur. Connecte-toi, puis clique sur Allow (Autoriser). Le compte à utiliser est celui qui possède déjà le worker : son adresse contient maxime-parriaux-25, donc probablement ton adresse Gmail.

Tu dois voirDans le terminal : Successfully logged in. Pour vérifier à tout moment : npx wrangler whoami affiche ton e-mail.
Si ça coinceMot de passe oublié : « Forgot password » sur dash.cloudflare.com. La première fois, npx demande s'il peut installer wrangler : réponds y.
2

Envoyer la nouvelle version du worker

toi · 1 min

Toujours dans le dossier worker :

npx wrangler deploy
Tu dois voirQuelques lignes, puis à la fin l'adresse du worker :
https://open-setlist-proxy.maxime-parriaux-25.workers.dev

Vérifie que le relais répond :

curl -i https://open-setlist-proxy.maxime-parriaux-25.workers.dev/bands/00000000000000000000000000000000
RéponseCe que ça veut dire
401 et Missing band tokenC'est bon, le relais est en ligne.
400 et Missing ?url= parameterC'est encore l'ancienne version : le déploiement n'est pas passé.
Si ça coince « You are not authenticated » : refais l'étape 1.
Wrangler demande de choisir un compte : prends celui dont le nom contient maxime-parriaux-25.
L'adresse affichée est différente de celle ci-dessus : note-la et donne-la à Claude, il faudra la mettre aussi dans le code.
Un message d'erreur sur « Durable Objects » ou « migrations » : copie-le tel quel à Claude.
3

Dire à l'application où est le relais

toi ou Claude · 1 min

Le plus simple : écris à Claude « c'est déployé », il fait cette étape et la suivante.

Pour le faire toi-même, ouvre Settings → Secrets and variables → Actions sur GitHub, onglet Variables, bouton New repository variable :

NameRELAY_URL
Valuehttps://open-setlist-proxy.maxime-parriaux-25.workers.dev

C'est une « variable », pas un « secret » : l'adresse n'a rien de confidentiel.

Ou en une commande :

gh variable set RELAY_URL -R ParriauxMaxime/open-setlist --body "https://open-setlist-proxy.maxime-parriaux-25.workers.dev"
4

Reconstruire l'application

toi ou Claude · 3 min d'attente

L'application lit l'adresse du relais au moment où elle est construite. Il faut donc la reconstruire une fois.

Sur GitHub, ouvre Actions → CI/CD, bouton Run workflow, branche main, puis le bouton vert Run workflow.

Ou en une commande :

gh workflow run ci.yml -R ParriauxMaxime/open-setlist --ref main
Tu dois voirUne ligne qui tourne dans l'onglet Actions, puis une coche verte au bout de trois minutes environ.

Vérifier que ça marche

La synchro de groupe est allumée

Ouvre l'application et recharge la page deux fois (la première fois, le navigateur peut encore montrer l'ancienne version ; si l'app est installée, ferme-la et rouvre-la). Va dans Synchro.

Tu dois voirLe bloc « Synchroniser avec votre groupe » avec les boutons Créer un groupe et Rejoindre un groupe, à la place du message « La synchro de groupe n'est pas activée… ».

Créer le groupe

Place-toi sur le profil qui contient les chansons du groupe, pas sur « Demo » (menu des profils en haut du menu de gauche, « + Ajouter un profil » si besoin). Puis Synchro → Créer un groupe, donne son nom, Créer. Tu obtiens un lien.

Envoie ce lien aux musiciens. Chacun l'ouvre, confirme, et reçoit les chansons. Ensuite, chacun appuie sur Synchroniser avec le groupe quand il veut envoyer ou recevoir des changements.

À garder en lieu sûrLe lien contient le code du groupe. Qui l'a peut lire et modifier les chansons. Si tous les appareils le perdent, personne ne peut plus rejoindre le groupe. Garde-en une copie.

Les partitions PDF

Sur un appareil : ouvre une chanson, Partitions, ajoute un PDF, Enregistrer, puis Synchro → Synchroniser avec le groupe. Tu dois lire « Partitions : 1 envoyées, 0 reçues ». Sur un second appareil, après synchro : « 0 envoyées, 1 reçues », et la partition s'affiche en mode scène.

La session live

Deux appareils du groupe ouvrent la même setlist en mode scène. Sur l'un : menu ⋮ → Session live → Mener. Sur l'autre : ⋮ → Session live → Suivre. Change de morceau sur le premier : le second suit. Une étiquette « Je mène » ou « Je suis » apparaît en haut ; elle est grisée quand l'appareil n'a pas de réseau.

Dépannage

Ce que tu voisQuoi faire
L'app dit toujours que la synchro de groupe n'est pas activéeVérifie le nom exact de la variable (RELAY_URL), que la reconstruction est terminée en vert, puis recharge deux fois.
« Le serveur de synchro est injoignable »Refais le test curl de l'étape 2. S'il répond 400, le worker n'a pas été mis à jour.
Le test curl est bon, mais l'app échoue quand mêmeL'app est servie depuis une autre adresse que https://parriauxmaxime.github.io. Corrige ALLOWED_ORIGINS dans worker/wrangler.toml, puis refais l'étape 2.
« Aucun groupe ne correspond à ce code »Le lien est incomplet ou vient d'un autre groupe. Recopie-le en entier depuis Synchro → Inviter des membres sur un appareil déjà membre.

Bon à savoir

Coût : rien. L'offre gratuite de Cloudflare suffit largement pour un groupe ; la consommation se voit dans le tableau de bord Cloudflare, rubrique Workers & Pages.

Revenir en arrière : supprime la variable RELAY_URL et relance l'étape 4. La synchro de groupe s'éteint ; les chansons restent sur chaque appareil.

Tester sans rien mettre en ligne : dans worker, npx wrangler dev --port 8787 ; dans un autre terminal, à la racine, RELAY_URL=http://127.0.0.1:8787 yarn dev.
