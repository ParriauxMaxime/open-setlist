Le morceau change, le son change

Test avec ta tablette Android et ton Mac. Rien ne passe par Internet.

Sur le Mac

1
Lance le programme compagnon
2
Une page s'ouvre avec une adresse et un QR code

Laisse-la ouverte : elle affiche chaque message reçu.

Sur la tablette, dans Chrome

3
Vise le QR code avec l'appareil photo

Open Setlist s'ouvre sur Paramètres → Scène : MIDI, adresse déjà remplie. Tablette et Mac sur le même wifi.

4
Mon instrument : Clavier. Coche « Envoyer mon son au changement de morceau »
5
Appuie sur « Tester »

Chrome demande s'il peut joindre ton réseau local : Autoriser.

Tu dois lire « Connecté à … Le MIDI sort sur Open Setlist ».

6
Appuie sur « Envoyer »

Sur le Mac, la page du compagnon affiche le message reçu.

Sur scène

7
Ouvre une setlist, « Jouer », change de morceau

En haut, l'étiquette MIDI 17A devient bleue quand le son est parti. Rouge : pas parti, touche-la pour renvoyer. MIDI – : pas de code dans ce morceau.

D'où vient le code ? Clavier : la première ligne de la grille (17A).
Les autres : champ « Sons (MIDI) » du morceau.
Suivre le meneur En mode scène, menu ⋮. Éteint par défaut.
Passe par le compagnon, donc en wifi.

En Bluetooth, à la place du wifi

B
Paramètres → Scène : MIDI → Bluetooth → Connecter

Choisis Open Setlist dans la liste, puis « Envoyer ».

Brancher Ableton

A
Préférences → MIDI : entrée « Open Setlist », coche Télécommande
B
Deux racks l'un dans l'autre

Dehors : 4 chaînes, une par lettre. Dedans : une chaîne par son. Relie chaque sélecteur de chaîne à une macro.

C
Mode affectation MIDI (Cmd+M), clique la macro

Sur la tablette : « Seulement la lettre » pour la macro du dehors, « Seulement les chiffres » pour celle du dedans.

À valider avec la personne qui règle Ableton Deux contrôles (lettre, chiffres) : c'est ma proposition, les numéros se changent dans « Détails MIDI ».
